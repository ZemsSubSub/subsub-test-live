# Изменённые стили относительно прода

Документ для передачи разработчикам: перечень мест, где стили прототипа **отличаются от `app.subsub.io`** или **добавлены с нуля** (в проде такого нет).

> **База:** значения токенов (`css/tokens.css`) **не менялись** — все отклонения используют существующие токены дизайн-системы. Большая часть UI повторяет прод; ниже — только дельты. Раздел **A** — переопределения существующего прод-UI (осознанные), **B** — net-new (в проде отсутствует, стиль создан с нуля), **C** — точечные акценты внутри перенесённых/новых компонентов.

---

## A. Переопределения существующего прод-UI (осознанные отклонения)

### A1. Единый светлый хедер модалок превью
- **Прод:** шапки модалок превью несогласованы — `video` голая рамка; `audio/pdf/docx/table/code` — **тёмная** панель `#0f172a` со своим close; `image` — сторонний PhotoSwipe.
- **Прототип:** все 7 модалок приведены к **одному светлому** паттерну (`.ml-viewer__head`, хелпер `head()` в `build/build-mlfiles.js`): белый фон, нижняя граница `--color-shade-200`, слева цветной icon-badge по типу, чёрное имя файла, единый `.ml-viewer__close`.
- **Файлы:** `build/build-mlfiles.js`, `css/styles.css` (`.ml-viewer__*`).

### A2. Action-bar в шапке каждого превью
- **Прод:** действий над файлом в шапке превью нет (только в меню «⋮»).
- **Прототип:** в шапку превью добавлены `.ml-viewer__actions` — кнопки **Share** и **Download** во всех типах (заглушки). Чтобы не открывать «⋮» ради действия.
- **Файлы:** `build/build-mlfiles.js`, `css/styles.css` (`.ml-vbtn`).

### A3. YouTube-флоу разделён на «Send to YouTube Studio» + «Metadata»
- **Прод:** пункт «⋮» у видео называется **`Create metadata`** (один флоу генерации + публикации); красной кнопки в шапке превью нет.
- **Прототип:** два независимых экшна. **`Send to YouTube Studio`** — в «⋮» + **красная** кнопка (`.ml-vbtn--publish`) в шапке видео-превью (единственный акцентный CTA); финал — отправка черновика в Studio («Sent to YouTube Studio» + «Open in YouTube Studio»). **`Metadata`** — отдельный пункт «⋮» (только видео), генерация без канала → сохранение `<база> - metadata.txt` в авто-папку **Metadata**. Оба сохраняют `.txt` (Send — на финале).
- **Файлы:** `build/build-mlfiles.js`, `css/styles.css`, `js/media.js`.

### A4. Фиолетовая кнопка Download на публичных страницах
- **Прод:** у `BaseButton` **нет** фиолетового мода; primary — чёрный.
- **Прототип:** на публичных страницах шаренной ссылки кнопка **Download фиолетовая** (`.pub-download`, `background: var(--color-purple-900)` = `#b351f6`). Осознанное разовое исключение.
- **Файлы:** `css/styles.css` (`.pub-download`).

### A5. Иконки в спрайте — themeable
- **Техническое:** в SVG-спрайте `ml-*` жёсткий чёрный (`#000`/`#19191A`) заменён на `currentColor`, чтобы иконки красились через CSS `color` (чёрные в таблице, акцентные в бейджах). На проде — иконки-компоненты Vue.
- **Файлы:** `build/gen-media-icons.js`.

## B. Net-new — в проде отсутствует, стиль создан с нуля

### B1. Публичные страницы шаренной ссылки (`shared-file*.html`)
- В реальном продукте гостевого лендинга по ссылке **нет** (шеринг внутренний, между залогиненными). Весь слой `.pub-*` — net-new: лёгкий шелл (лого + «Sign up free»), атрибуция «Shared by …», карточка превью, промо-баннер.
- Разнесено на файлы по типам: `shared-file-video/audio/pdf/spreadsheet/archive.html`.
- **Файлы:** `shared-file*.html`, `css/styles.css` (`.pub-*`).

### B2. Нотификация «поделился файлом»
- Вариант `.notif-item--file` (иконка типа файла + «[Имя] shared [файл] with you.» + Dismiss/View) — net-new, по референсу дизайнера.
- **Отклонение по цвету:** иконка типа файла сделана **фиолетовой** (глиф `--color-purple-900` на бейдже `--color-purple-100`).
- **Файлы:** `home.html`, `css/styles.css` (`.notif-item--file`, `.notif-item__fileicon`).

### B3. Транскрибация (весь флоу — net-new; в проде пункта Transcribe нет)
Построено по визуальному образцу прод-**конвертации**, но со своими стилями:
- **Топбар-бейдж** `.jobs__badge` — **indigo** (`--color-blue-20` фон + `--color-indigo`), намеренно **не оранжевый**, чтобы отличать от конвертации. Состояния: `⟳ Transcribing N` → `✓ Transcribed` (только смена иконки, без смены цвета).
- **Попап** «File transcription» (`.jobs__panel`, `.job*`) — карточки задач с под-строками по языкам, кнопка «Go to file ›».
- **Модалка Transcribe** (`.ml-transcribe*`): нативный `<select>` в обёртке `.ml-select` + мультиселект-дропдаун `.ml-multi` (поиск + чекбоксы + чипы).
- **Превью транскрипта** (`.ml-transcript*`, `.ml-tl`): реплики с таймкодами (таймкод — `--color-indigo`).
- **Категория файла `transcript`**: иконка субтитров (`ml-transcript` ← репозиторный `OutlineIconTranscript`), бейдж `--color-blue-20`/`--color-indigo`.
- **Файлы:** `home.html` (бейдж), `build/build-mlfiles.js` (модалки/пункт), `css/styles.css` (`.jobs*`, `.job*`, `.ml-transcribe*`, `.ml-select`, `.ml-multi*`, `.ml-transcript*`, `@keyframes jobs-spin`/`job-progress`/`ml-row-flash`), `js/media.js`.

## C. Точечные акценты (внутри перенесённых/новых компонентов)

- **C1. icon-badge по типу файла** в шапках модалок (`.ml-viewer__badge--<kind>`): pdf=red, video=indigo, audio=violet, image=green, document=blue, spreadsheet=green-dark, code=purple, transcript=indigo. (Не токен-изменение — раскраска бейджей существующими токенами.)
- **C2. Модалка «Metadata»:** Hashtags и Timecodes — **фиолетовым** (`--color-violet`); дропдаун каналов раскрывается **вверх** (`.ml-chan__menu { bottom: 100% }`) из-за близости к нижнему краю модалки.
- **C3. Прогресс-бар транскрибации** — взят из дизайн-системы: компонент **`BaseGradientProgressBar`** (Storybook → *Data Display/ProgressBar*): трек `bg-shade-100` h-3px, бар `linear-gradient(90deg, purple-900 0%→78.98%, transparent)`. (Соответствие системе, не отклонение — отмечено для трассируемости.)
- **C4. Таблица Files** обёрнута в плоскую карточку-`surface` (`.ml-table-wrap`, border `--color-shade-200` + radius 12, без тени) — по компоненту `BaseTable` из сторибука.

## Что НЕ менялось (для ясности)

- Значения токенов `css/tokens.css` — без изменений.
- Порядок и состав сайдбара/саб-меню, активное состояние пункта (`bg-purple-100 text-purple-900`) — как на проде.
- Видеоплеер приведён к прод-виду (кастомная панель в стиле Plyr) — это соответствие, не отклонение.
- Структура формы модалки «Metadata», модалки шеринга — по проду/референсу (светлые стили как в апке).
